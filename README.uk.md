# Orange Buddy 🟠

[English](README.md) · **Українська**

Маленький помаранчевий піксельний компаньйон, що живе над полем вводу Claude Code. Він гуляє туди-сюди, кліпає, дістає ноутбук, поки Claude працює, каже, який інструмент зараз запущено, і святкує конфеті, коли хід завершено.

У репозиторії дві версії. Встановіть одну з них (обидві мають команду `/buddy`):

| Плагін | Що робить |
| --- | --- |
| `orange-buddy-click` | Повна версія: тицяйте його, перетягуйте, клацайте поруч, щоб він туди прибіг, права/середня кнопка миші, стрілки, `space`, `h`, `d`, `s`, `w`. Якщо тицяти забагато, у нього паморочиться голова. |
| `orange-buddy-calm` | Спокійна версія без реакцій на мишу й клавіші: просто гуляє, кліпає і реагує на роботу Claude. |

`/buddy` ховає або показує компаньйона.

## Мова

За замовчуванням Помаранчик говорить англійською. Щоб він говорив українською, як в оригіналі:

```
/buddy uk
```

`/buddy en` повертає англійську. Вибір запам’ятовується між сесіями.

## Встановлення

У полі вводу Claude Code в терміналі:

```
/plugin install orange-buddy-click --marketplace Fupper-cYBBR/orange-buddy
```

або спокійна версія:

```
/plugin install orange-buddy-calm --marketplace Fupper-cYBBR/orange-buddy
```

З оболонки:

```bash
claude plugin install orange-buddy-click --marketplace Fupper-cYBBR/orange-buddy
```

У десктопному застосунку, де `/plugin` не працює: натисніть + біля поля вводу, далі Plugins, Add marketplace з `Fupper-cYBBR/orange-buddy`, потім Add plugin.

Відповідайте `y`, щоб додати маркетплейс, і виберіть область встановлення.
